# Fog mode: the maths

Generated by `backend/examples/fog_math.py`. Implementation: `web/static/pc/fog.js`.

| CRR equation | Used in fog mode as |
|---|---|
| Coherence, C = (1/sigma) integral v_FR dt | Each clearing, including the explorer's moving lantern, grows along the Fisher-Rao geodesic at constant speed, so the fog parts evenly |
| Rupture, a unit event at t(n+1) | Arriving at a place is the event: the clearing there blooms out from lantern size to full size, and the explored count rises by one |
| Regeneration, m_new = q m + (1 - q) Phi | Its fixed point is Phi; with Phi = 1, every path walked and place visited stays clear for good, as in a game |
| Lived surplus, S = C - C* >= 0 | Distance walked minus the straight line from the start: shown as wandering, valued rather than penalised |
| Omega = 1 | Only a normalisation: noise octave weights sum to one |

Opacity is theta / pi with theta = 2 asin(sqrt(p)), where p is the chance a spot is still unexplored times the fog cover there. On the flat map, S >= 0 is the triangle inequality; the sheet's intrinsic-circle assumptions are not claimed here.

Paths: the explorer follows real footpaths and roads, pre-computed by `manage.py build_fog_routes` from the self-hosted OpenStreetMap basemap (ODbL, (c) OpenStreetMap contributors). Short hops go on foot, preferring paths and quiet streets; longer ones go by road. Each walk's trail is a chain of capsules along the route's bends. An illustration for the game, never directions.

The look (domain-warped noise, light from the west-south-west, a marine layer thick offshore and on the coastal plain and thinner inland, onshore drift from the north-west) is ordinary graphics, not a claim of the equations.
