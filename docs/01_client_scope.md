# Contract-focused delivery map (Kim's provided specification)

## Week 1–2: discovery and design — $1,500 on written acceptance
- Kickoff, content/source audit, audience needs and site map.
- Mobile and desktop wireframes, homepage direction, simple design system and page templates.
- Daniel Friedman GIS discovery; available APIs/file formats/rights documented; independent fallback identified.
- Explicit editor workflows and status vocabulary approved by Kim.

## Week 3–4: content and CMS — $2,000
- 40 **human-verified draft** records with complete required fields and provenance.
- Working admin/editor/community contributor workflow; moderated suggestions do not auto-publish.
- At least two independent organization-controlled superusers.

## Week 5–6: functional website — $3,000
- Directory, inclusive filters, accessible non-map listing, calendar and expiries.
- Interactive local map with published pins if feasible; documented approved fallback otherwise.
- No live reliance on source sites for normal basemap rendering; preprocessed licensed local map assets.

## Week 7: QA, manual, tutorials — $2,000
- Responsive/common-browser tests; WCAG 2.2 AA audit, fix major issues, record remaining exceptions.
- Editable operating manual and PDF; 3–5 tutorials, backup/restore test, accounts/licences inventory.

## Week 8: training, acceptance and launch — $1,500
- Two practical training sessions.
- Two staff each demonstrate edit/publish/archive listing, manage event, moderate suggestion, update point on map and manage account.
- Written final acceptance and organization-controlled account, hosting, asset and source-code handoff.

## Out of scope by default
Production conversational API agent; GPS-based user journeys; self-running WhatsApp announcements; GIS sharing with Daniel before technical/legal permission; continuous-learning GPU; custom biodiversity sensors; emergency navigation guarantees; automatic species ID as verified fact.

## Budget and scope change
Do not change deliverables, costs or deadline without written client approval. Annual hosting/services envelope $500–$1,000 **quoted by vendors**; optional API usage is separate and capped.
