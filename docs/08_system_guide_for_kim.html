Why a server as well as GitHub?

GitHub Pages can only hand out finished pages. It cannot run code, keep a database, sign people in, hold the secret key that pays for Opus, store photos, or record a steward's approval. Those jobs need a server. No paid GitHub plan adds one: GitHub Team and Enterprise add teamwork features, not hosting.

A bigger server is not needed. A suggested split lowers the cost instead:

5. How the maths keeps tokens down and trust up

Every trust check runs as code on our server, at no token cost: the 75 percent show rule, the honesty check on each sentence, the sealed log, the published-facts check, removal of photo GPS data, and the five-or-more rule for map counts. Opus is used only for language and judgement. These four changes take typical use from $1,415 to $574 of Opus a year, with the same model and the same checks.

  • Call Opus to read a question only when the rules cannot. The rules parsed 33 of 34 test questions. Today the code calls Opus on every question; we assume 1 in 5 still needs it.
  • Send only what an answer needs. Eight fields from at most four listings instead of whole records, roughly halving the words sent.
  • Reuse checked answers. The same understood question gets the same checked answer until a listing changes, which the projection version number tells us exactly. We assume 1 in 4 questions repeats.
  • Batch what can wait. Photo checks, website comparisons and the digest lines run overnight at half price. A website page that has not changed since last month is never sent to Opus at all, because identical text is not new evidence.

A daily limit makes the budget a guarantee. At heavy use, after about 200 worded answers in a day, Compass answers in its plain template from the same checked listings, at no cost.

6. The Quadruplicate, lightly connected

The Quadruplicate is a public, open-source snapshot of Crescent City civic information: news, government meetings, a community calendar and a safety alert board, rebuilt on a schedule from public sources. It has no sign-in or live API, and it states no licence.

  • Calendar: each month our server reads its free calendar feed. Family-relevant events become Pending items in the steward's digest, labelled "reported by The Quadruplicate", and appear only once approved.
  • Safety and meetings: link out to its safety board and meeting pages rather than copying them.
  • Rights first: before republishing any of its text, ask its maintainers (CrescentCity@tuta.com) and log the answer, as our data-rights rules require.

7. Built today, and still to build

Built: public map and listings, joining, Compass with the trust checks and sealed log, moderated suggestions, the admin review queue, and the Opus connection, which is switched off.

To build within the delivery budget: Compass limited to members, photo upload with GPS removal and the photo check, the monthly website check, the steward's monthly digest with Approve buttons, the Quadruplicate feed, the four token savings, and the daily limit.
