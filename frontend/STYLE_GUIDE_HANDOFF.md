# Aesthetic direction is intentionally left to the project lead

This kit does not impose branding beyond **mobile friendly, uncluttered, calm, accessible**, and unobtrusive attributions. The owner supplies Pleasant Crescent photographs, palette, crescent branding, typography and final image choices; Claude Code builds components, responsive CSS, WCAG-friendly controls and a content-managed home page for review.

## UX quality targets
- Public homepage asks one optional question, not a form gate.
- Default to the **list** with filters; let user switch to map. All map functionality must have a list/form equivalent.
- Clearly labelled layer toggles, readable attributions, source/vintage legends and offline/currentness indicators.
- Only published sources appear. A pin should expose cost, ages, access status, last-verified date and contact/source.
- No full-screen notification storms; saved choices can preserve preferred filters, without tracking a child's routes.
- Mobile touch targets and readable labels; view continuity after network disconnect if local assets cached according to your own policies.
- Avoid using a photograph to imply a currently accessible place without human verification.

## Editor flow
Add listing -> category, age and cost -> map marker chosen, coordinate display -> source and licensing -> photo upload / metadata review -> submit draft -> reviewer approves -> public update. Mark each field's provenance and last-verified date.
